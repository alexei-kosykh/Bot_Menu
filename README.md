# 🤖 Бот управления расходами

Telegram-бот для автоматического распознавания чеков, отслеживания расходов и управления бюджетом с интеграцией Google Sheets.

## ✨ Возможности

- 📱 **Распознавание чеков**: Автоматическое сканирование QR-кодов и OCR текста
- 💰 **Отслеживание бюджета**: Установка лимитов и мониторинг расходов
- 📊 **Аналитика расходов**: Статистика по категориям и периодам
- 🔄 **Оффлайн режим**: Кэширование данных при недоступности интернета
- 👥 **Многопользовательский**: Поддержка нескольких пользователей
- 📝 **Ручной ввод**: Возможность добавления расходов вручную

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

**Примечание:** Если возникают проблемы с установкой Pillow на Python 3.13, попробуйте:

```bash
# Альтернативная установка Pillow
pip install --upgrade pip
pip install Pillow --only-binary=all

# Или установите совместимую версию
pip install Pillow==10.3.0
```

### 2. Настройка Google Sheets

1. Создайте новую Google Таблицу
2. Поделитесь ею с сервисным аккаунтом Google Cloud
3. Создайте файл `credentials.json` с ключами сервисного аккаунта
4. Обновите ID таблицы в `get_access_table.py`

### 3. Настройка Telegram бота

1. Создайте бота через [@BotFather](https://t.me/botfather)
2. Получите токен и добавьте его в `my_private_keys.py`
3. Настройте список разрешенных пользователей

### 4. Запуск

```bash
python bot.py
```

## 📋 Требования

### Обязательные зависимости
- Python 3.8+
- Google Cloud сервисный аккаунт с доступом к Google Sheets
- Telegram Bot Token

### Опциональные зависимости

Бот работает без них, но функциональность ограничена:

#### QR-коды
```bash
pip install pyzbar

# Системные зависимости:
# Linux: apt-get install libzbar0
# macOS: brew install zbar
# Windows:
# 1. Скачайте zbar DLL: https://github.com/mchehab/zbar/releases
# 2. Поместите zbar64.dll в C:\Windows\System32\
# 3. Или установите через conda: conda install zbar
```

#### OCR (распознавание текста)
```bash
pip install pytesseract
# Linux: apt-get install tesseract-ocr tesseract-ocr-rus
# Windows: Скачать с https://github.com/UB-Mannheim/tesseract/wiki
```

#### Оптимизация изображений
```bash
pip install opencv-python
```

## ⚠️ Предупреждения при запуске

Если видите предупреждения типа:
```
⚠️  Библиотека pyzbar не установлена. QR-коды не будут распознаваться.
```

Это нормально! Бот продолжит работу с ограниченным функционалом:
- Без pyzbar: только OCR распознавание
- Без pytesseract: только QR-коды
- Без opencv: базовое OCR без оптимизации

## 🎯 Использование

### Команды бота
- `/start` - Начало работы
- Отправьте фото чека для автоматического распознавания
- Используйте кнопки для ручного ввода и управления бюджетом

### Формат ручного ввода
```
Магазин | Сумма | Категория
Пример: Пятерочка | 500.50 | Продукты
```

## 📁 Структура проекта

```
├── bot.py                 # Основной файл бота
├── handlers.py           # Обработчики команд
├── receipt_handler.py    # Обработка чеков
├── receipt_scanner.py    # Распознавание изображений
├── expense_manager.py    # Управление расходами
├── budget_commands.py    # Команды бюджета
├── get_access_table.py   # Подключение к Google Sheets
├── logger_config.py      # Конфигурация логирования
├── test_bot.py          # Тестовый набор
├── keyboards.py          # Клавиатуры бота
├── state.py             # Состояние пользователей
├── my_private_keys.py   # Секретные ключи (не в репозитории)
├── requirements.txt     # Зависимости
└── cache/               # Кэш для оффлайн режима
    ├── expenses_cache.json
    └── budget_cache.json
```

## 📊 Google Sheets структура

Бот использует следующие листы:
- **Чеки**: История расходов
- **Бюджеты**: Плановые бюджеты по месяцам
- **Меню_Сегодня_Полное**: Меню (опционально)
- **База_рецептов**: Рецепты (опционально)
